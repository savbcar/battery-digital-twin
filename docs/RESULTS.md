# Verified Baseline Results

These numbers were generated by executing the repository's deterministic baseline
with `seed = 42`. They are not hand-entered targets.

## Baseline setup

- Truth model: 2-RC Thevenin ECM
- Estimator: manual NumPy 2-RC EKF
- True initial SOC: 85%
- EKF initial SOC: 70%
- Initial SOC error: -15 percentage points
- Voltage noise standard deviation: 8 mV
- Current noise standard deviation: 50 mA
- Estimator parameters intentionally differ slightly from truth parameters

## Engineering interpretation

The EKF corrects a large initial SOC error because terminal voltage provides
information about the hidden state through the nonlinear OCV-SOC relation.
Pure coulomb counting integrates current but has no measurement correction, so
its initial offset persists.

The low reconstructed-voltage error is useful, but it is not by itself proof of
accurate SOC: voltage fit and SOC observability are related but not identical.
The state error metrics and robustness studies therefore remain essential.

## Portfolio-safe statement

Under the repository's deterministic synthetic benchmark, the 2-RC EKF reduced
SOC RMSE to **0.446%** despite a **15 percentage-point initial
SOC error** and converged to the ±2 percentage-point band within
**15 s**.

Do not generalize these synthetic-benchmark numbers to a production cell or BMS.
